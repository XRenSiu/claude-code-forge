## 四问（每问必答，不允许"差不多"）

1. **实体是不是我认的那些？** 列出形态草案里的核心实体，逐个标 ✓ / ✗（✗ 写明该是什么）。
2. **有没有技术上对、产品上错？** 指出任何"照字面做对了、但不是这个产品该有的形状"的决策。
3. **每条形态决策从哪条规律推出来的？** 无引用锚（`PSL-NNN` / `UI-n` / `A-n` / `DP-n`）的决策
   = 推不出来 → 列出；借来的引用（真正来源是别处，只是挂了最近的规律）同样列出。
4. **含谓词的决策，能对一份最小样例算出来吗？** 逐条走查："当且仅当 / ∧ / 缺一不算 / exit 0"这类
   条件，给一个最小输入，看能不能算出唯一判定；算不出来 = 谓词欠定，现在补，不要留给 L5 写 fixture
   时发现——那时测试已经锁了，改它要走变更提案（dogfood 2026-09-05，I-56 / I-58）。
