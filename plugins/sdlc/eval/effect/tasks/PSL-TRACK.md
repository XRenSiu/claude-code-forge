# PSL 轨的隐藏集怎么写

报告里登记的空白：**形态对不对没法用 pytest 判**。所以 PSL 轨一直没有题。

解法不是去判形态，是把 PSL 轨真正的失败模式拆成两半，两半都机器可判：

## 一、语义半：朴素的领域模型会被证伪

PSL 轨的典型失败是「技术正确、产品错误」——照字面实现，交出一个 `created_at` 加日历筛选器。
这**不是**形态问题，是领域模型问题，而领域模型的错误可以用行为测出来：

> 隐藏集里放几条**只有当领域模型对了才会通过**的用例。
> 朴素模型不是"少了点什么"，是**在这些用例上给出相反的答案**。

例：「按上个月搜索记忆」。朴素模型用写入时间，正确模型用事件发生时间。
一条昨天补录的、发生在上个月的记忆，两种模型给相反的结果。一条 pytest 就分开了。

## 二、判断半：不可判的部分必须被**路由**，不是被猜

剩下那部分（这个交互对不对、这个措辞好不好）确实机器判不了。但可以机器判的是：
**arm 有没有把它当成"我说了算"的事悄悄定掉。**

sdlc 自己的 C 档纪律就是答案：不可机械判的验收要写成 `kind: human`，带 judge 与 evidence，
路由到 G3。所以隐藏集的第二半检查产物里有没有这样一条路由记录——
有 = 它知道这里轮不到自己拍板；没有 = 它替产品经理做了决定，而且没人知道。

**这一半不判断"路由得对不对"，只判断"有没有路由"。** 前者是品味，后者是纪律。

## 每道 PSL 题的形状

| 检查 | 权重 | 判什么 |
|---|---|---|
| `test_semantics.py` | 5 | 领域模型被证伪：朴素模型在这里给相反答案 |
| `test_naive_trap.py` | 2 | 朴素实现的具体特征没有留在代码里（字段名 / 结构） |
| `test_human_routed.py` | 3 | 不可判的那部分被路由了：产物里有一条带裁决人的开放问题 |

外加两个欠定槽，与 TASK 轨同一套口径（只在 arm 新增的内容里找证据）。
