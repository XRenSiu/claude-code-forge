# 中文 AI 味模式库

**使用原则（来自 qu-ai-wei，本库沿用）：单独出现不算 AI 腔；短段落内反复堆叠、脱离具体内容、空转修辞才是。**
所以 humanlint 报的是密度不是命中；本库每条都给"什么时候不该改"。

**语域门**：技术方案 / 设计文档 / 复盘 / 邮件 是本 skill 的默认语域——书面、克制、有判断、有数字。
公众号式的口语化（"emm""啊对了"）、情绪层、五感描写在这个语域里是**新的 AI 味**，禁止注入。
学术论文语域允许保留"进行 + 动词"和被动句。

## A. 结构层（读者最先感到"别扭"的地方，优先级最高）

| # | 模式 | 例 | 改法 | 何时不改 |
|---|---|---|---|---|
| A1 | 总-分-总 | 引言预告三点 → 三点 → "综上所述"复述 | 删预告与复述；结尾放下一步或未决点 | 论文摘要体裁 |
| A2 | 首先/其次/最后 骨架 | 三段各以序数词开头 | 删序数词；用内容衔接（上句尾→下句首） | 真正的时间/操作顺序（安装步骤） |
| A3 | 面面俱到、正反两面 | 每个观点都"一方面…另一方面…" | 选一边，说为什么；另一边写成"没选它，因为…" | 真正的中立综述 |
| A4 | 段尾升华 | "这体现了…/彰显了…/折射出…的深层逻辑" | 删 | 从不 |
| A5 | 均匀的 ~20 字句、均匀段长 | 每句 18-25 字、每段 3-4 句 | 长短交错；允许 6 字短句和 60 字长句 | 从不 |
| A6 | 列表替代论证 | 四条"**标签**：一句话"，项间实有因果 | 展开成段，写出"所以/但是/前提是/代价是" | 真并列无序项（目标、改动清单、配置） |
| A7 | 空路标 | 句首 此外/另外/与此同时/值得注意的是 | 删；删完接不上说明内容缺环 | 从不需要 |
| A8 | 套路化开头 | "随着业务的不断发展…""在当今…背景下" | 用触发事件 + 日期 + 数字开头 | 从不 |
| A9 | 抽象占位例子 | "某地""某位用户""A/B/C 三种情况" | 用真实/具体的名字与数值（来源里有的） | 来源确无 → 标 `[需核实]` |
| A10 | 指代不敢省 | 每句重复完整名词短语 | 中文允许无主句；上文清楚就省 | 法律/合同文本 |

## B. 句法层

| # | 模式 | 例 → 改 | 备注 |
|---|---|---|---|
| B1 | 万能动词 + 名词化 | 进行优化 → 优化；作出贡献 → 贡献；开展调研 → 调研；对…进行处理 → 处理 | 余光中 1987；CCL 2023 语料印证 |
| B2 | -性/-化/-度 派生堆叠 | 可读性高 → 好读；系统性地 → 系统地/整体上；稳定性得到提升 → 更稳了/P99 从…到… | |
| B3 | "的"字堆叠 / 长定语前置 | "基于用户历史行为数据的个性化推荐算法的优化方案" → "推荐算法要改。它现在按用户历史行为算……" | 一句最多两个"的" |
| B4 | 被动滥用 | "问题被有效解决" → "问题解决了"；"我不会被吓倒" → "吓不倒我" | 中文被动天然带不幸义 |
| B5 | 排比三件套 | "灵活、高效、可靠" / "不仅 A，而且 B，更重要的是 C" | 只留真有的；两个够就写两个 |
| B6 | 不是 X 而是 Y / 与其说…不如说 | 反复出现 | 删否定半句，直接说 Y |
| B7 | 目的状语尾巴 | "…，以实现…/以确保…/从而…" 每段一个 | 升格成句并给证据，或删 |
| B8 | "和/与/及/以及" 堆叠 | ChatGPT 11.76/篇 vs 人 4.13 | 用顿号、"跟"、拆句 |
| B9 | "之一" "们" "关于/有关" "在…方面" | "重要原因之一" → "一个重要原因"；"用户们" → "用户" | 欧化冗余 |
| B10 | 弱动词 + 抽象宾语 | "造成九十八人死亡" → "死了九十八人"；"对性能产生了显著影响" → "P99 涨了 3 倍" | |
| B11 | 翻译腔四类（yage.ai） | 物理动作动词写心理（"接住反馈" → "收到"）；形容词提前下判断（"更锋利的重构："）；抽象名词主语 + 评价词尾（"工程上的现实比数字难看"）；有译法的英文词不译（"context 不崩"） | 归化自检：盖住原文用中文重说一遍 |
| B12 | 形容词代替事实 | "显著提升""大幅降低""效果良好" | 换数字；没有就写"没测，量级估计…" |

## D. 正向目标（写成这样才像人；现成工具几乎都没有这一节）

- 简单的"是/有"句："这个接口是同步的""它有两个调用方"。不用"作为""充当""标志着""扮演"。
- 敢下定论："这是最慢的一个接口""上次就是它出的事"。
- 具体时间与专名："8 月 27 日""SendGrid""`orders-api`"，不是"近期""某第三方服务"。
- 有人在场："我建议""我没选""我最担心的是""我和产品确认过"。
- 至少一处毛边：承认一个没想清楚的点、一个没测的数、一个和主流不同的观察。**这不是加口语词，是加判断。**
- 关键术语重复用，不轮换同义词（"缓存"就一直叫"缓存"，不要第二次变成"缓存层"第三次变成"缓存机制"）。
- 短句存在：每 300 字至少一句 ≤12 字。

**方案对比**
