## Classification decisions (Judgment 1)

### Excluded as UI elements (Judgment 1, step 1)

- none. The plugin has no UI layer; the only UI-shaped word is the docs' `卡/Card`, which passes step 1 ("a self-contained unit of work for a
  context-free agent" is describable without a screen) — see the verifier collision under Convergence.

### Excluded as implementation details (Judgment 1, step 2)

- `skill` / `agent` / `script` / `asset` — framework constructs of the plugin runtime. Operate on: the lifecycle. Domain representation: **Node**
  (kind skill | agent | human | stage). Scripts (`verify_*.py`, `lint_cards.py`, `sdlc_state.py`, `pr-poll.sh`) are the compiled Control (edge
  `guard:`, `predicate_scripts`), not objects. Assets are templates of artifacts.
- `ledger.md`, `trace.jsonl`, `graph.yaml`, `loops.yaml`, `routing.yaml`, `state.json` — file projections. The objects are what they hold
  (Event, Node, Loop, rules, Run); the files go to `composition`.
- `.done_when.lock` — a signature record with no identity apart from its Contract → `Contract.lock` value object.
- `pr-poll.sh` counters / watermark — review_loop control state; Loop memory, not an object.

### Excluded as actions/behaviors (Judgment 1, step 3)

- `回流 / reflow`, `升级 / escalate`, `冻结 / freeze`, `拆卡 / split`, `派发 / dispatch`, `归档 / archive`, `对账 / reconcile`, `提案 / propose` → `relationships` / `behaviors`.
- `闸 / 预门 / 自动门` (mechanical pre-gate) → a guard behaviour on an edge or an `advance` prerequisite, **not** a Gate (Gate is defined as human-signed).
- `routing rule R01–R16` → `rules` (the existence of routing is constitution R011/R012; the table's contents are policy — Judgment 3 below).
- `fail`, `reflow`, `waiver`, `escape` → kinds of Event (Pattern 8 tense/aspect: state is a field, not an object).

### Relationships — verb filtering

The docs inventory yielded 11 domain verbs (`01b`); the code inventory 118 infrastructure verbs (all dropped). 16 relationships entered `dos.yaml`.

**Notable verb decisions**:
- `FREEZES` kept (docs: "G2 判据冻结") over `SIGNS` — signing is the act, freezing is the effect on the Contract.
- `HANDS_OFF_TO` kept as the single Node→Node verb; the seven edge types (sequential / conditional / fan_out / fan_in / loop_back / interrupt / handoff) are
  attributes of the edge (graph.yaml `type:`), not seven relationships — Failure 2 (every verb a relationship) avoided.
- `CAUSED_BY` kept in the effect→cause direction (design-notes: append-only logs point backwards); `CAUSES` is the inverse only.
- `IMPLEMENTS` (commit → CARD → AC) kept because trace.py `impact` walks it; `REFERENCES` / `DEPENDS_ON` edge types dropped as too generic for the DOS.
- `AMENDS` chosen over the raw edge name `SUPERSEDES` for Event→Contract (the event supersedes an AC *version*; at object level it amends the Contract).

## Skill friction (dogfood report for dos-extract)

1. **`inventory.py` returned 0 nouns** on a plugin whose objects live in YAML/JSON/Markdown; it parses only `class`-like definitions in ts/js/py/go/rs/java/kt,
   ignores `.sh`, and has no `--include-ext` / schema mode. Its "fewer than 10 nouns" warning fired; the code-side roster had to be hand-lifted from
   `state.schema.json` `$defs`, YAML keys and enum values. Suggest: YAML/JSON key + `$defs` extraction, or document that data-heavy repos need a manual code roster.
2. **`inventory.py --exclude` excludes by directory *name*, not path** (`--exclude eval` drops every `eval/` at any depth) — acceptable here, but undocumented.
3. **`verify_dos.py` UI-suffix check has no whole-word exemption and no waiver**: the domain's canonical `Card` (卡) is rejected as `*Card`. SKILL.md says
   "the script errs strict, the judge relaxes", but exit 1 is not relaxable → forced a rename (Q001). Suggest a whole-word / `synonyms:`-aware exemption list.
4. **Template fields that did not fit a plugin-as-codebase**: `properties.<id>.type` assumes entity fields (used `ref` / `value` / `enum` informally);
   `objects.<name>` has no `synonyms:` slot (added ad hoc — the closure checks `verify_issue.py --dos` / `lint_cards.py --dos` compare raw names and will not see it);
   `bounded_contexts.downstream_contexts` has no `translation_notes` (added anyway); `scope.audience` default list is UI-product-flavoured.
5. **`docs_extraction_prompt.md` gives no mechanical aid** (counts are "approximate frequency … count actual occurrences" by hand); a tiny grep helper would make
   the docs inventory reproducible. This run used an ad-hoc regex count (`01b`).
6. **`decisions_template.md` "Inventory summary"** presumes a code-noun count > 0 and a `Pruned framework noise` list from inventory.py; both had to be reinterpreted.
7. **SKILL.md 接线 says the extracted dos.yaml is the closure source for `verify_issue.py --dos` and `lint_cards.py --dos`**; both compare `dos_slice.objects`
   against `objects` keys only — the renamed `WorkUnit` vs canonical `Card` will bite there unless synonyms are honoured (Q001).
8. Minor: `verify_dos.py` reports missing softer sections as `info` but prints them only when missing; a `sections_present` list would make the report self-describing.
   `methodology.md` says the extracted DOS is "always 0.1.0" — followed.
